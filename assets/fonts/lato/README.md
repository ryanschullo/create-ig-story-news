# Lato Black

Original Lato Black font, weight 900, used for chart titles, axes and legends.
Source: https://raw.githubusercontent.com/google/fonts/main/ofl/lato/Lato-Black.ttf
License: SIL Open Font License; see OFL.txt.

Georgia is not bundled here. Do not silently substitute another font for Georgia
when a renderer is asked to set body or source text.

For this data figure, actual Georgia was obtained for runtime use from the
official Microsoft Core Fonts installer:
https://downloads.sourceforge.net/project/corefonts/the%20fonts/final/georgi32.exe
The installer SHA-256 was
`2c2c7dcda6606ea5cf08918fb7cd3f3359e9e84338dc690013f20cd42e930301`.
Its EULA and unmodified fonts remain local runtime files; they are not included
in this repository. Pass the actual Georgia TTF path explicitly to the Story
renderer; do not use the system's Noto Serif alias as a substitute.
